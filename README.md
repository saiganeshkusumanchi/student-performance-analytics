# Student Performance Analytics System

## Project Objective
To analyze student marks and attendance using Python.

## Technologies Used
- Python
- NumPy
- Pandas
- Matplotlib

## Dataset
The dataset contains student ID, name, department, Python marks, Maths marks, AI marks and attendance.

## Features
- Read student data from CSV
- Display dataset information
- Calculate total and average marks
- Assign grades
- Identify pass and fail students
- Find highest and lowest performers
- Analyze subject-wise averages
- Display top-performing students
- Generate a subject-wise average graph
- Save analyzed data to CSV

## Files
- main.py - Main Python program
- data.csv - Original student dataset
- analyzed_data.csv - Processed results
- subject_average.png - Subject average graph
